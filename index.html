Selected Research & Engineering Projects

Multi-Tenant LLM Inference Resource Pooling & Dynamic Isolation

AI Infra

Provincial Computing Grant · Lead Researcher · 2025.10 — Present

Addressing the interference problem when multiple tenants share GPU/NPU resources for LLM inference. We profile prefill (compute-bound) vs. decode (memory-bound) stages using Nsight/msprof and request-level tracing, revealing up to 127% TPOT p99 degradation under long-context interference.

  • Cross-runtime instrumentation via LD_PRELOAD/dlsym for both CUDA and ACL — no modification to vLLM/SGLang mainline
  • Resource pooling at 5% minimum granularity; goodput and TTFT scale near-linearly with allocated share
  • Three scheduling modes: strict isolation, elastic borrowing, and priority-based preemption
  • Unified benchmark suite across 2/3/4/8 tenants on Qwen2/2.5/3 model families

Operator-Level Cross-Platform Inference Optimization

Systems

Collaborative Research · 2025.04 — 2025.08

Investigating hardware-software co-design for deploying SOTA object detectors (D-FINE) on heterogeneous platforms. Identified that grid_sample fallback on TensorRT 8.x / CANN 6.3 was the primary bottleneck.

  • Reformulated deformable attention from bilinear to discrete sampling — resolved cross-platform compatibility
  • Achieved ~100% throughput improvement on Ascend CANN 6.3 with <1% mAP loss
  • Backward-compatible with CUDA/TensorRT 8.x, preserving legacy deployment (CUDA 10.1/10.2)
  • Standardized 8-model repository with Docker-based reproducible training pipeline

Statistical Randomness Testing for Encrypted Traffic Detection

Security

Research Project · 2026.07 — 2026.09

Demonstrated that Shannon entropy + RNN cannot distinguish encrypted backups from naturally high-entropy data (overlapping distributions at 1e-5 granularity). Introduced NIST SP 800-22 randomization tests as discriminative features.

  • Three-tier architecture: Block (8KB) → Chunk (1GB) → Replica, with 32MB sliding oversampling (30→960 samples)
  • 17-dimensional feature selection; Logistic Regression outperforms tree models under oversampling
  • AUC 0.9998, Recall 99.6%, FPR 0.0045%; F1 improved from 0.928 to 0.975
  • Companion work on anomaly detection using NSGA-II multi-objective optimization: 100% detection rate, 0% false positive

Tree Ring Segmentation via Foundation Model Adaptation

Computer Vision

Guangzhou Institute of Forestry · Project Lead · 2025.06 — 2025.09

Designed a SAM3-Adapter segmentation architecture with CLIP visual-semantic guidance for high-density tree ring counting in ancient tree core images.

  • System accuracy >95%; exhibited at the National Ancient Tree Protection Week as a flagship outcome

Generative AI
